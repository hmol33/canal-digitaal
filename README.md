## Installatie

### Vereisten

- Node.js 18+
- npm of yarn
- Git

### Installatie

```bash
git clone https://github.com/hmol33/canal-digitaal.git
cd canal-digitaal
npm install
```

## Gebruik

```bash
# Start de ontwikkelserver
npm run dev

# Build voor productie
npm run build

# Test
npm test
```
