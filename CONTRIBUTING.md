# Contributing

Bedankt voor je interesse om bij te dragen aan dit project!

## Hoe te bijdragen

1. **Fork** de repository
2. **Creëer** een feature branch (`git checkout -b feature/amazing-feature`)
3. **Commit** je wijzigingen (`git commit -m 'feat: add amazing feature'`)
4. **Push** naar de branch (`git push origin feature/amazing feature`)
5. **Open** een Pull Request

## Code Stijl

- Volg PEP 8 voor Python code
- Gebruik 4 spaces voor indentatie
- Houd regels maximaal 127 tekens
- Gebruik duidelijke variabelenamen
- Voeg comments toe waar nodig

## Commit Berichten

Gebruik [Conventional Commits](https://www.conventionalcommits.org/):

- `feat:` - Nieuwe feature
- `fix:` - Bug fix
- `docs:` - Documentatie wijzigingen
- `style:` - Code stijl wijzigingen (geen functionaliteit)
- `refactor:` - Code refactoring
- `test:` - Testen toevoegen of wijzigen
- `chore:` - Build process of tooling wijzigingen

## Rapporteren van Bugs

Gebruik GitHub Issues om bugs te rapporteren. Voeg toe:
- Een duidelijke titel
- Stappen om te reproduceren
- Verwacht vs. werkelijk gedrag
- Je Kodi versie en besturingssysteem

## Veel Gestelde Vragen

### Kan ik het project gebruiken voor mijn eigen IPTV provider?

Dit project is specifiek ontwikkeld voor Canal Digitaal. Het kan mogelijk worden aangepast voor andere providers, maar dit is niet het doel van dit project.

### Hoe voeg ik een nieuwe zender toe?

Zenders worden automatisch opgehaald van de Canal Digitaal API. Je kunt de zenderlijst aanpassen via de kanaalkeuze in de addon instellingen.
